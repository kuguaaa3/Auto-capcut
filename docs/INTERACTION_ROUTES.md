# 对话路由与控制点

## 1. 顶层意图路由
| 用户意图 | 触发示例 | 优先执行 | 何时问 |
|---|---|---|---|
| 新剪辑 | “把文件夹素材剪成30秒” | 识别素材、推荐或采用风格、生成计划并执行 | 风格冲突/核心素材不可用时 |
| 选择风格 | “用搞笑反转skill” | 锁定指定 Skill，按需加载专项技能 | 不存在或互斥时 |
| 查看风格 | “有什么剪辑风格” | 列短名单+一句话用途 | 不问 |
| 自定义风格 | “用我的温柔宠物” | 查找并加载本地用户 Skill | 同名或缺文件时 |
| Skill 研究 | “找更好的卡点skill” | 官方/开源候选 → 源文件核查 → 质量评分 → 建议 | 安装/执行陌生脚本前 |
| 参考片学习 | “学这条片子的节奏” | 源视频镜头分解 → 形成风格提案 | 保存到技能库前 |
| 修改剪辑 | “第3镜缩短1秒” | 定位当前版本并增量修改+QA | 对象不唯一时 |
| 切换风格 | “换成治愈系” | 基于原始素材创建新版本，不破坏旧版 | 覆盖已有成品时 |
| 导出 | “要mp4和剪映草稿” | 能力校验 → 执行支持的格式 → 回读验证 | 剪映格式不支持时给替代选项 |
| 保存为Skill | “这套剪法存起来” | 提取可迁移规则 → 展示短摘要 → 经确认落盘 | 必须确认 |
| 继续项目 | “继续上次狗狗项目” | 定位项目状态、校验文件路径与工具能力 | 存在多项目歧义时 |
| 问答 | “为什么把这个镜头放开头” | 从审定计划与素材证据解释 | 不问 |

## 2. 风格选择优先级
1. 用户本轮明确指定：优先且锁定。
2. 当前项目已确认风格：默认继承。
3. 用户让 AI 自选：根据素材推荐 1 个，列出 2 个备选（不强迫选）。
4. 缺少用户意图又无法判断：问“一条更偏搞笑还是温馨？”。
5. 新用户 Skill 先做合法性、结构和引用检查；无效不可静默替换为别的风格。

## 3. 必须交用户决定的关口
A. **第一次风格路由**：仅在用户未说明且风格会显著影响结果时，给推荐并允许改选；用户若说“你决定”则直接执行。
B. **编辑范围发生重大变化**：例如删除剧情要点、换素材、做多版本或破坏性覆盖，展示变更摘要。
C. **新增外部 Skill 的主动代码执行/安装或素材外传**：明确取得授权。
D. **用户最终导出目标不支持**：说明支持的选择，不假称成功。
E. **从成片学习并入库 Skill**：明确问“保存/只留本项目”。
其他内部扫描、规则加载、质量检查、文件写盘不问。

## 4. 普通交互举例
用户：将 materials/ 的狗狗素材剪成30秒，开头搞笑，结尾温柔。
Codex：建议“搞笑反转→温情收尾”，沿用9:16；可换“治愈慢节奏/高能快剪”。若你没有其他要求，我按推荐执行。
用户：就这个，直接剪。
Codex：执行中根据需要只汇报真正的阻碍，完成后：“已完成第1版。视频位置..., 工程位置...；检测...；可以说‘第三镜缩短1秒’。”
用户：第三镜缩短1秒、最后音乐小一点。
Codex：在新版本精确修改、重新验收，保留旧版。
用户：满意，保存成我自己的Skill。
Codex：简短列出风格规则与拟存名称 → 确认 → 落地到 learned-skills/ 并写版本。

## 5. 中断与恢复
- 用户切换风格：保留源版、新建版本，不覆盖。
- 用户说“停止”：当前不可中断操作的状态记录，停止后续步骤；不宣称已取消正在运行的外部工具。
- 插件断开：保留已确认的计划和文件，标记 blocked 并提示重连后恢复。
- 用户切换工程：先保存当前项目状态，再处理新工程。
- 发现低质内容：用质量门禁指出问题与推荐修正；可按用户设置自动修一般性质量问题，但不能擅自重编剧情。

## 6. 反馈风格
永远以“结果/下一步”开头，默认2-4句。不打印内部模型思考、海量 JSON、未请求的库清单；提供“展开计划/查看审查报告”按需读取文件。
