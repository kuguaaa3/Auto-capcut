# 交付验收标准（不可用模拟替代真机）

## A. 静态与自动化（持续集成）
- [ ] A01 唯一入口 Skill 元信息可被目标 Codex 发现；未重复注册。
- [ ] A02 不包含独立网站/桌面UI/后台服务（必要的本地一次性工具例外）。
- [ ] A03 项目状态可原子写盘并在新会话恢复，含版本和错误状态。
- [ ] A04 缺失/损坏/非视频素材的错误正确。
- [ ] A05 用户指定 Skill 优先级高于AI推荐与项目默认。
- [ ] A06 每种主风格有合法格式、适用边界、至少一个独立验证用例。
- [ ] A07 外部 Skill 研究有来源、许可证、版本与信任标记；拒绝默认自动执行陌生脚本。
- [ ] A08 素材入出点在实际素材时长内，时间基准统一，帧/微秒边界无越界。
- [ ] A09 片段时间线、字幕时间和音轨结构满足合同。
- [ ] A10 断点恢复不重复执行已成功的非幂等操作。
- [ ] A11 局部修改有新版本且不破坏旧版。
- [ ] A12 用户学习生成的 Skill 去除了绝对路径/一次性镜头时间码，能新建工程复用。
- [ ] A13 不支持格式明确返回“不可用”而非空路径、假文件或伪成功。
- [ ] A14 同名用户 Skill 更新保留旧版，回退可用。
- [ ] A15 独立项目/多个文件夹操作不会错写到另一项目。
- [ ] A16 开源许可证和来源有记录，个人非商用场景不作商用用途推断。

## B. CapCut 真机强制验收
记录：OS和版本、Codex版本、CapCut版本、官方插件版本、测试日期、相关授权、每项工具的实际输入输出，以及可复核的文件/截图。未经实测不得打勾。
- [ ] B01 已授权的官方 CapCut 插件可被当前 Codex 工具发现。
- [ ] B02 使用至少3段用户允许的本地视频，真实创建可编辑工程。
- [ ] B03 能真实删除无效片段、裁剪入出点、排序；重新打开看到相同顺序。
- [ ] B04 使用自然语言“将第三镜缩短1秒”，实际改变工程，其他镜头保留。
- [ ] B05 至少执行一次字幕和音频调整，实际轨道或成片可以核验。
- [ ] B06 视频文件可独立播放，时长、尺寸、音轨及画幅符合请求。
- [ ] B07 CapCut 工程能再次打开并继续编辑（若官方支持对应交付）。
- [ ] B08 断线后恢复编辑/错误状态，不误称已完成。
- [ ] B09 用户中途换风格后旧版仍在，修改的新版本可用。
- [ ] B10 从审定成片提取自定义 Skill，下一项目复用并生成实际工程。

## C. 国内剪映草稿可选强制验收
- [ ] C01 针对用户指定的国内剪映专业版版本保存兼容性记录。
- [ ] C02 生成的不是 MP4/计划 JSON，而是剪映真实工程/草稿。
- [ ] C03 真实打开编辑器、可以改字幕或一段视频、保存并重新打开。
- [ ] C04 不支持时提供如 CapCut 工程/MP4 的可用替代，绝不虚报剪映成功。

## D. 内容与体验
- [ ] D01 开头/中段/结尾遵从用户描述且有可见的叙事与动作连续性。
- [ ] D02 不以标题捏造素材内容；无法从素材找到的剧情明确标缺。
- [ ] D03 字幕无明显遮挡、断句错误和时间漂移。
- [ ] D04 无意外黑帧、静音断层、音爆、错误横竖比例。
- [ ] D05 风格选择时展示少而精的选项，用户能用一句话改选。
- [ ] D06 常规路径无需重复填写表单，每次需确认的环节有明确理由。
- [ ] D07 输出路径准确，确实可从文件系统打开，带简短QA摘要。
- [ ] D08 文档与产品状态相符，禁止声称未验证的功能已上线。

## 通过判定
- **开发包完成**：文件、调研、规格、审计齐全，不等于系统已实现。
- **可测试工程完成**：A类通过、T01..T13实施，但B类未通过则仍不能称为“自动剪辑可用”。
- **核心产品完成**：A + B（实际工具支持的操作）+ D 通过，C类按明确的支持矩阵标注。
- **国内剪映草稿支持**：仅C类全部真机验收后标记支持，不能被核心产品自动推定。
证据以真实媒体与项目文件为主，测试脚本/Mock结果只证明辅助模块。
