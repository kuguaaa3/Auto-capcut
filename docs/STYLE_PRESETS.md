# 十种主风格 Skill 的实现规格（开发者参考）

每个主风格都应是可观察、可反驳的剪辑决策集，而非绝对的镜头秒数模板。下列默认行为只在素材和用户目标符合时应用。

| ID | 应强调的核心 | 绝不能机械套用 | 审查依据 |
|---|---|---|---|
| comedy-reversal | 因果铺垫、动作夸张但清楚、有效反应镜头、笑点时机 | 每一秒都插特效；乱序导致笑点提前曝光 | 观众能理解前因后果，反转有依据 |
| pet-healing | 宠物动作特写、真实行为、留白、情绪渐进 | 一律慢动作加钢琴；脱离素材编造“忠诚”故事 | 共情建立于真实镜头，声音不喧宾夺主 |
| narrative-drama | 镜头动因、人物/物体连续、视线/方位关系 | 每镜头同样时长；为了刺激破坏人物位置 | 核心情节完整且连续 |
| short-form-hook | 开头价值清楚、精简等待、信息密度有变化 | 无证据夸张钩子、过度频繁跳切 | 第一时间理解主题，后续有兑现 |
| vlog-documentary-lite | 真实时间流、环境感、真实记录、必要的B-roll | 过度假转场、毁掉真实场景声音 | 连贯、自然、情绪可信 |
| talking-head | 保留语义、精简口水词、字幕可读、证据画面 | 删错关键限定词、频繁切B-roll打断说明 | 原意未改变，字幕正确 |
| beat-montage | 重拍/弱拍有层次、段落起伏、节奏与动作对应 | 每一拍都硬切、高潮之前无铺垫 | 音画同步且有变化 |
| product-ad | 卖点顺序、产品辨识、镜头运动、CTA可读 | 夸张不存在的功能、画面完全遮挡产品 | 卖点可从素材/用户资料证实 |
| cinematic-brand | 色彩连贯、呼吸感、音效空间、构图连续 | 无依据套黑边/颗粒/过度调色 | 画面风格统一且主题清楚 |
| explainer-documentary | 事实准确、资料标注、信息层次、节奏引导 | 编造引述、滥用无关素材 | 内容与证据相互对应 |

## 风格路由规则
- 同一任务最多选一个主风格；可添加经用户批准的副风格修饰。
- 风格冲突时用户显式需求永远优先，禁止静默折中。
- 风格无法通过素材实现：呈现“能做到/缺少什么/推荐如何处理”，不臆造素材。
- 每种风格至少在本地素材测试、官方CapCut真机测试和一个错误样本上验收。
- 更具体的技法和原始资料：docs/RESEARCHED_SKILLS.md 与 research/upstream/。
