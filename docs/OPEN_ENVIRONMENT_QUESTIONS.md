# 开发时必须在目标电脑探测的环境条件

这些不是需要重新向用户讨论的产品需求，而是运行时探测项。优先自动检测；需要用户许可才请求一次。

1. Codex 客户端版本与是否支持 mattpocock 插件安装流程。
2. CapCut × Codex 当前账号/地区是否已开放，可用授权方式与实际官方工具名称。
3. 电脑系统 Windows/macOS，CapCut 版本，是否安装国内剪映专业版、具体版本。
4. 官方插件能否读本地媒体路径，是否要求主动上传或有文件大小限制。
5. 官方工具是否可写入时间线、回读/局部修改、保存与视频导出。
6. CapCut 工程是本地文件/目录还是云端工程标识；目标用户要哪一种交付。
7. 国内剪映能否独立打开兼容路径生成的项目，是否只在Windows或某版本可行。
8. 哪些剪辑功能（字幕、转场、BGM、音量、调色）需要用户确认或编辑器手动最后一步。

**必须记录为 supported / unsupported / unknown / blocked，不允许当作推测或自动默认。** 不具备实际授权、无安装环境时，将相关任务标为 blocked with recovery instruction；继续把其他可独立完成的代码和测试做好。
